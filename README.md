# 🔐 Secure Gateway (C++)

A beginner-friendly C++ project that simulates a role-based access selection system through a command-line interface.

## 📌 Overview

Secure Gateway is a small educational project created to practice fundamental C++ programming concepts while building a simple access-control workflow.

Users can select a role from a menu, such as:

- **Admin**
- **Analyst**
- **Guest**

The project focuses on control flow, user input, and role-based program logic.

## 🛠️ Concepts Practiced

- C++ fundamentals
- `if` / `else` conditional statements
- User input and output
- Variables and data types
- Menu-driven program design
- Input validation *(as implemented)*

## 💻 Getting Started

### Prerequisites

- A C++ compiler, such as `g++`

### Compile

```bash
g++ main.cpp -o secure-gateway
```

### Run on Linux

```bash
./secure-gateway
```

## 🎯 Project Goals

- Improve C++ programming skills
- Practice structured control flow
- Learn how to handle user input
- Build a foundation for future security-related programming projects

## ⚠️ Disclaimer

This project is for educational purposes only. It simulates role selection and is **not a production-ready authentication or security system**.
